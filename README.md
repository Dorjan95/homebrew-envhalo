# Homebrew tap for EnvHalo

EnvHalo is a macOS menu bar utility that keeps the active development
environment visible while you work. Releases in this tap are signed with an
Apple Developer ID and notarized by Apple.

## Install

```sh
brew install --cask dorjan95/envhalo/envhalo
```

EnvHalo requires macOS 14 Sonoma or later.

## Update

```sh
brew update
brew upgrade --cask envhalo
```

## Uninstall

Before uninstalling, open EnvHalo Settings and disable any shell or IDE
integrations that you do not want to keep. Then run:

```sh
brew uninstall --cask envhalo
```

Binary downloads and checksums are available from the repository's Releases
page.
